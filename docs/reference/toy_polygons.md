# Synthetic polygons for H3 workflow testing

A deterministic `sf` dataset containing synthetic polygon geometries
used in examples, tests, and demonstrations of H3 coverage and
compaction workflows.

## Usage

``` r
toy_polygons
```

## Format

An `sf` object with 4 rows and 2 columns:

- geometry_id:

  Character identifier for the synthetic geometry.

- geometry:

  Polygon geometry in EPSG:4326.

## Source

Synthetic data generated by `h3compactR`.

## Details

The geometries represent several polygon forms relevant to spatial
coverage testing: a regular polygon, an irregular polygon, a more
complex polygon, and a polygon containing an interior hole.
